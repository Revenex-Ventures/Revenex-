## Add a Before Item
Find beforeItems array. Add:
{ number: N, icon: IconName, title: 'Title', desc: 'Desc' }

Find afterItems array. Add:
{ icon: IconName, title: 'Title', desc: 'Desc' }

- Before card: red tinted bg — never make white
- After card: white bg with brown border — never make dark
- Center arrow between cards must stay
- Numbered circles on Before items must stay
