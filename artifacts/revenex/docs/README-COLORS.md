# Colors Documentation

## Purpose
Explains the premium beige design language used for this update.

## Source of Truth
- src/index.css

## Main Palette
- Beige background: #f7efe4 to #efe2d0
- Muted slate: #5f766f
- Warm gold: #a3865b
- Neutral text: #2f2b26

## How to Edit
- Keep the palette restrained and premium.
- Avoid introducing bright or playful accents.
- Adjust existing utility classes in src/index.css instead of introducing a new system.
